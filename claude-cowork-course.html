What Is Claude Cowork?

Cowork is Anthropic's answer to a simple observation: people were using Claude Code — a developer terminal tool — for everything from sorting vacation photos to building slide decks. Rather than force non-technical users into a command line, Anthropic wrapped Claude's agentic architecture in a friendly desktop interface.

The result is a tool that, in Anthropic's own words, transforms Claude from a chatbot into a digital coworker.

Chat vs. Cowork: The Core Difference

Under the Hood

Cowork is built on the same Claude Agent SDK that powers Claude Code. When you give it a folder, your files are mounted into an isolated Linux virtual machine (using Apple's Virtualization Framework on macOS). Code runs in that sandbox — real file changes are then written back out to your machine. This architecture means:

  • Claude cannot access files outside folders you explicitly grant
  • Python scripts, shell commands, and other tools run in a controlled environment
  • The underlying model is Claude Opus 4.6 with a 1 million token context window

Core Workflow: How Cowork Thinks

Understanding Cowork's internal execution model makes you a dramatically better user. Here's exactly what happens after you press send:

1

Analysis & Planning

Claude reads your goal, inspects any files you've given access to, and forms a detailed plan. It breaks large work into concrete sub-tasks. You'll see this plan before execution begins — this is your chance to redirect.

2

Sub-agent Spawning

For complex tasks, Claude spins up multiple sub-agents that work in parallel. One might be summarizing documents while another is building a spreadsheet structure. This dramatically reduces total execution time.

3

Execution in the VM

Code, shell commands, and file operations run in the isolated virtual machine. Live progress indicators appear in the interface — you can see exactly what Claude is doing at each step.

4

Check-ins & Permission Requests

For significant or potentially destructive actions — like deleting files — Claude pauses and asks for your explicit permission. You'll see a prompt and must click "Allow" to proceed.

5

Output Delivery

Finished files are written directly to your file system in the working folder. Claude summarizes what was done and highlights any decisions it made during execution.

Monitoring & Steering Mid-Task

You don't have to watch. But you can — and sometimes should. If Claude's plan looks wrong, type a correction at any point. The agent will incorporate your feedback into its remaining work. Think of it like leaving a voicemail for a colleague; they'll hear it and adjust.

Queuing Tasks

You can queue up tasks before Claude finishes the current one. Type your next request in the input area and send it. Claude will add it to its work queue and tackle it after completing the current task (or in parallel, if appropriate).

⚠️
Keep the app open

Closing Claude Desktop ends your Cowork session immediately. Long tasks require an open app. If you need to run multi-hour jobs, adjust your system's sleep/screen-lock settings accordingly.

Usage Allocation

Cowork tasks consume significantly more of your usage allocation than regular chat because each task involves many more model calls, code executions, and tool uses. To get the most from your plan:

  • Batch related work into single sessions rather than starting a new session per sub-task
  • Use standard chat for simple questions that don't need file access
  • Monitor usage at Settings → Usage in the Claude interface

Writing Great Cowork Prompts

Unlike chat prompts where Claude can ask clarifying questions easily, Cowork prompts should be goals, not commands. The better you describe the outcome, the less mid-task steering you'll need.

The GOAL Framework

  • G — Goal: What finished state do you want?
  • O — Output: What format/file type should the result be in?
  • A — Approach/Constraints: Any rules, style, or limitations?
  • L — Location: Where should outputs go? What folders to use?

Prompt Examples: Weak vs. Strong

❌ Weak Prompt
Summarize my documents.
✅ Strong Prompt
Read all .md and .txt files in the /notes folder. For each file, write a 2–3 sentence summary. Compile all summaries into a single Word document called "notes-overview.docx" saved in the same folder. Use a clean heading for each source file name.
❌ Weak Prompt
Make a spreadsheet from my receipts.
✅ Strong Prompt
I have a folder of receipt photos (JPEGs) in /receipts/2025. Read each image and extract: merchant name, date, amount, and category (Food, Travel, Office, Other). Create expenses.xlsx with one row per receipt, a SUM formula at the bottom, and a second sheet with a pivot table by category. Save to /receipts/.
❌ Weak Prompt
Clean up my downloads folder.
✅ Strong Prompt
Look at my /Downloads folder. Sort files into subfolders by type: Images/, Documents/, Installers/, Archives/, Other/. Rename files with creation dates prepended (YYYY-MM-DD_filename). Do NOT delete anything. Show me a plan first before making any changes.

Prompting Patterns by Use Case

Research & Synthesis

Template
Read all files in [folder]. Extract [specific data points]. Synthesize into [output format] at [location]. Highlight any [contradictions / gaps / key themes].

File Organization

Template
Review files in [folder]. Sort into [categories] based on [criteria]. Rename using [naming convention]. Do NOT delete anything. Show me a plan before executing.

Report Generation

Template
Using data from [source files], generate a [type] report in [format]. Include: [sections]. Apply [style guidelines]. Save as [filename] to [location].

Data Processing

Template
Load [file]. Clean it by [rules]. Compute [metrics/formulas]. Output as [xlsx/csv] with [specific sheets/columns]. Flag any rows that [condition].

Global & Folder Instructions

One of Cowork's most powerful features is the ability to give Claude persistent standing instructions so you never have to repeat context. There are two levels: global (applies to every session) and folder-specific (applies when working in a particular directory).

Global Instructions

Use global instructions for things that are always true about you, your role, and your preferences:

Example Global Instructions
I'm a clinical research nurse. When writing reports or summaries, use clear, professional language suitable for study sponsors. Avoid medical jargon when writing for non-clinician audiences. Always save backup copies of original files before modifying them. Prefer .docx for documents and .xlsx for data tables. My working timezone is US Central.

To set global instructions:

  1. Go to Settings → Cowork inside Claude Desktop
  2. Click "Edit" next to Global instructions
  3. Type your instructions and click Save

Folder Instructions

Folder instructions add project-specific context that activates whenever Claude is working in that folder. This is ideal for:

  • Project codenames and background
  • Specific output naming conventions
  • Files Claude should always consult first
  • Stakeholder names and preferences
Example Folder Instructions (in a clinical trial folder)
This folder contains documents for Study ABC-2024-001, a Phase II oncology trial sponsored by Pharma Corp. PI is Dr. Jane Smith. Always reference the protocol (protocol-v3.pdf) when making any eligibility assessments. Output any participant data tables with de-identified IDs only (format: SUBJ-XXXX). Never include full names in any output file.

Tips for Effective Instructions

  • Be specific, not vague. "Use professional tone" is less useful than "Write at a 10th-grade reading level suitable for patient-facing materials."
  • Set guardrails. Explicitly state what Claude should NOT do (e.g., "Do not delete any file without asking first").
  • Update often. You can update instructions mid-session by typing a new preference in chat. Cowork will incorporate it.
  • Layer them thoughtfully. Global = who you are; Folder = what this project is.

Safety & Best Practices

Cowork has real power — which means real consequences when things go wrong. Anthropic is transparent about the risks. This module teaches you how to use Cowork safely.

🚨
Cowork Can Modify and Delete Files

By default, Claude will ask for explicit permission before permanently deleting files. However, it can edit, rename, overwrite, and reorganize files without a separate confirmation for each action. Always work in a dedicated folder — not your entire Documents or Downloads directory.

The 5 Golden Rules of Cowork Safety

📁

1. Use Dedicated Folders

Never point Cowork at your root directory or a folder containing irreplaceable files without backups. Create a /cowork-projects/ or /claude/ directory as your working space.

💾

2. Backup First

Before any task that modifies existing files, back them up. Include "back up originals before editing" in your global or folder instructions to automate this.

📋

3. Review the Plan

Before saying "go ahead," read Claude's plan carefully. If anything looks off — wrong files, unexpected scope — redirect it immediately. Plans are your best defense against surprises.

🎯

4. Be Specific About Destructive Operations

Explicitly forbid deletion or renaming in your prompts unless you want it: "Do NOT delete, rename, or move any file — only create new ones."

🔒

5. Watch for Prompt Injection

If Claude is processing files from untrusted sources (downloaded docs, emails, web pages), be aware that malicious content could attempt to hijack Claude's instructions. Don't process untrusted files with sensitive system access.

What Cowork CANNOT Do

  • Access files or folders you haven't explicitly granted
  • Permanently delete files without your confirmation (a permission dialog will appear)
  • Access the internet beyond your plan's network egress permissions
  • Store conversation history in Anthropic's cloud (it's saved locally)

Enterprise & Compliance Notes

⚠️
Not for Regulated Workloads

Cowork activity is NOT captured in Audit Logs, Compliance API, or Data Exports. Do not use Cowork for HIPAA-regulated patient data, financial records requiring audit trails, or other regulated workloads without first consulting your compliance team.

Advanced Techniques

Once you've mastered the basics, these advanced techniques will multiply your productivity and unlock use cases most users haven't discovered yet.

Cowork + Claude in Chrome

Claude in Chrome is a separate browser agent. When you pair both tools:

  • Claude can browse websites, extract data, and submit forms
  • Web-scraped data can be saved to your local Cowork working folder automatically
  • Great for: competitive research, price monitoring, gathering info from portals without APIs
Example: Cowork + Chrome Combined Task
Using Claude in Chrome, search PubMed for the 10 most recent clinical trials on GLP-1 agonists for type 2 diabetes published in 2025. Save each abstract and key metadata (NCT ID, phase, enrollment, primary endpoint) to a file called pubmed-glp1-2025.csv in my /research/ folder. Then create a summary report in Word format.

Skills: Office File Superpowers

Cowork includes built-in Skills that give it native handling for common file formats:

  • .xlsx — Read, write, create formulas, build pivot tables, format cells
  • .docx — Generate structured Word documents with headers, tables, and styles
  • .pptx — Create full slide decks with layouts, images, and speaker notes

You can also build custom Skills using the skill-creator plugin to teach Claude specialized behaviors for your workflow.

Parallel Task Queuing

While Claude is working, you can keep sending tasks. Cowork handles them as a queue (and sometimes in parallel). This pattern is powerful for batch work:

Batch Queue Pattern
[Task 1 — send first] Process all files in /raw-data/ and clean them (remove blank rows, standardize date formats, save to /clean-data/). [Task 2 — send immediately after, without waiting] Once the /clean-data/ folder is populated, create a master summary.xlsx that consolidates all files into a single table with a source column. [Task 3 — queue behind] Using the master summary.xlsx, generate a 5-slide executive PowerPoint called exec-summary.pptx.

Self-Maintaining Workspaces

One of the most powerful Cowork use patterns is setting up living workspaces that Claude can update on demand:

Workspace Setup Prompt
This /project-tracker/ folder is my ongoing project workspace. It contains: - inbox/ — raw files I drop in - processed/ — files you've worked on - reports/ — output reports - README.md — always keep this updated with a summary of what's in the folder When I ask you to "process inbox," read all new files in inbox/, extract key info, move them to processed/, and update README.md with what you found and any action items.

Context Window Maximization

Claude Opus 4.6 has a 1-million-token context window. In Cowork, this means you can feed it enormous amounts of data in a single session. Tips for large-context tasks:

  • Give Claude access to large corpora up front rather than feeding in pieces
  • Ask Claude to build an index or map of your files before starting work — this helps it reference materials efficiently
  • For analysis of large datasets, ask Claude to summarize incrementally into a running notes file it updates as it reads

Prompt Chaining with Files

Use files as communication between tasks. Have one Cowork session output a plan.md, then in a subsequent session, reference that plan:

Session 1
Analyze all files in /research/ and create a plan.md with a step-by-step outline for a comprehensive literature review report. Include what data to pull from each file and what sections the final report should contain.
Session 2
Follow the instructions in plan.md to build the complete literature review report. Save as literature-review.docx in /output/.
