The Claude Ecosystem

Anthropic offers Claude through five distinct surfaces, each designed for a specific mode of work. They share the same underlying models but differ in how you interact, what you can do, and who they're built for. Understanding the shape of the ecosystem is the first step to using it well.

ℹ️
One model, many doorways. All five surfaces give you access to the same Claude models (Haiku 4.5, Sonnet 4.5, Opus 4.5/4.6). The surface determines the interface, context model, cost structure, and what actions Claude can take — not which intelligence is doing the work.

Why Five Surfaces?

Each surface emerged from a specific user need. Chat began as an accessible general assistant. Projects were added when users needed persistent context across conversations. Claude Code was built for developers who wanted Claude inside their terminal and codebase. Cowork grew out of the observation that non-developers were using Claude Code for everything from file organization to writing — so Anthropic packaged the same power in a desktop UI. And the API has always existed for builders who want to embed Claude in their own products.

💡
The surfaces are complementary, not competitive. A developer might use the API to build a product, Claude Code to write that product, Projects to organize research about it, and standard Chat for quick one-off questions during the day. You're not choosing one — you're choosing the right one for each task.

Claude.ai Chat — The Universal Starting Point

Claude.ai Chat is the conversational interface available on web, iOS, Android, and desktop. It's the surface most people encounter first and the one that handles the broadest range of everyday tasks. Understanding its strengths — and its limits — tells you when to stay here and when to reach for something else.

🟢 What Free users can do in Chat

  • Full access to Claude Sonnet 4.5 (the same model as most paid interactions)
  • 200K-token context window per conversation
  • Image analysis, file uploads, and web search
  • Artifacts — create code, documents, and visualizations inline
  • Basic app connectors (Notion, Slack, Google Workspace, and more)
  • Up to five Projects with shared knowledge bases

What Chat Does Best

01
One-off questions and quick tasks. Chat is optimized for short-to-medium interactions where you want an immediate response. Drafting an email, explaining a concept, translating a paragraph, or debugging a single function — Chat handles all of these without any setup overhead.
02
Exploratory and creative work. When you don't know exactly what you need yet, Chat's conversational format lets you iterate freely. You can change direction mid-conversation, ask follow-up questions, and refine as you go.
03
Long-document analysis. Upload PDFs, code files, or large text documents and ask Claude to summarize, extract, critique, or transform them. The 200K-token context window means you can work with very long source material in a single conversation.
04
Mobile and on-the-go use. The iOS and Android apps bring Claude into your daily workflow without requiring a desktop. Voice input, quick lookups, and drafting content are all natural mobile use cases.

Where Chat Falls Short

Chat is stateless across conversations. Each new chat starts fresh — Claude has no memory of your previous sessions unless you use Projects, Memory (where available), or manually paste in prior context. This is the biggest practical limitation for ongoing work.

Chat also can't act on your computer or file system. Everything Claude produces lives inside the chat window as text or an artifact; you copy it out. For work that requires editing real files, running code, or managing a folder of documents, you need Claude Code or Cowork.

💡
Free tier tips for Chat: Use the full 200K context window — you have room to paste long documents. Select Haiku 4.5 for simple tasks to stay within your usage limits; save Sonnet for complex work. Upload images instead of describing them to save tokens. And if you hit your daily limit, your session resets after five hours — waiting it out costs nothing.

Model Selection in Chat

Paid subscribers can switch between Haiku 4.5 (fastest, lightest), Sonnet 4.5 (default, best balance), and Opus 4.5/4.6 (most capable, highest cost against your usage quota). Free users are served Sonnet 4.5. The rule of thumb: use the least-capable model that gets the job done well. Haiku is excellent for extraction, reformatting, and routine writing. Opus is worth the quota spend for complex code, long reasoning chains, and nuanced analysis.

Claude Projects — Persistent Context, Zero Repetition

Projects solve the biggest practical frustration with Chat: the need to re-explain your situation every time you start a new conversation. A Project is a persistent workspace where you define the context once — through uploaded documents and custom instructions — and every chat inside that project automatically inherits it.

🟢 What Free users get with Projects

  • Up to five Projects
  • Shared knowledge base per project (uploaded documents, code, text)
  • Custom project instructions (your standing context, role, preferences)
  • Separate chat histories per project
  • Artifacts scoped to the project

How the Knowledge Base Works

Each project has a knowledge base — a set of documents, files, and text you upload once. Claude references this knowledge automatically in every chat within the project. You don't need to re-upload your codebase, style guide, or research notes each session.

Paid users get an important upgrade here: when your knowledge base grows large enough to approach the context window limit, Claude automatically enables Retrieval Augmented Generation (RAG). This expands effective capacity by up to 10× while maintaining response quality. Free users are limited to the standard context window for knowledge storage.

ℹ️
Context is shared across the project, not across chats. Knowledge you upload to the project's knowledge base is available in every chat. But the conversation history of one chat does not bleed into another chat within the same project. If you want Claude to remember something from a previous conversation, add it to the knowledge base or project instructions.

Project Instructions — Your Persistent System Prompt

Project instructions let you write a standing context that Claude reads at the start of every conversation in the project. Think of it as a permanent briefing. Good project instructions typically include who you are and what the project is for, how you want Claude to respond (tone, format, depth), any constraints or house rules, and pointers to the key documents in the knowledge base.

💡
Make your project instructions specific. "You are helping me manage a marketing campaign for a SaaS product targeting mid-market IT buyers. Always write copy in an active voice. The brand guide is in the knowledge base." is far more useful than "You are a marketing assistant." The more specific your instructions, the less you need to re-explain in every chat.

When to Use a Project vs. Regular Chat

Situation Use

Ongoing work on a specific codebase, document, or topic Project

Team and Enterprise Sharing

On Team and Enterprise plans, Projects become a collaboration tool. You can share a project with specific teammates by email, share it org-wide, and set view or edit permissions. This turns Projects into a living knowledge base your whole team can query — effectively giving everyone on the team access to a shared AI assistant that knows your specific context.

💡
Free tier tip: You get five projects — use them strategically. Create one project per major ongoing area of your life or work: e.g., "Job search", "Side project", "Learning Python", "Home renovation". Upload your relevant documents once. You'll save significant usage quota by not re-pasting context every session.

Claude Code — The Developer's Agentic Environment

Claude Code is a command-line tool that gives Claude direct access to your development environment. It can read your codebase, write and edit files, run shell commands, install packages, and execute tests — all autonomously, with you reviewing its work in the terminal. It's available with Pro, Max, Team (premium seats), and Enterprise plans.

ℹ️
Claude Code was released in February 2025. By May 2025 it was generally available alongside Claude 4. It's available via a dedicated CLI tool and also through a web interface and iOS app as of late 2025.

What Makes Claude Code Different from Chat

In Chat, everything Claude produces is text you copy out. In Claude Code, Claude acts directly in your environment. The difference is like explaining to someone how to fix a bug versus hiring someone who sits down at your keyboard and fixes it themselves. Claude Code reads your actual files, not a pasted summary of them. It writes changes directly to disk. It runs your test suite and reads the results. It operates with far more context about your actual project state.

01
Full codebase context. Claude Code can read your entire repository at once rather than the fragments you remember to paste. This means it can understand how components relate, trace dependencies, and make changes that are coherent across files.
02
Agentic execution. Give Claude Code a goal — "add authentication to this Express app" — and it will make a plan, implement it across multiple files, run the tests, fix the failures it introduced, and return with a working result.
03
Non-coding tasks too. Developers quickly discovered Claude Code is excellent for non-coding work as well: organizing files, processing data in CSVs, batch-renaming assets, generating reports from logs. This ultimately led Anthropic to build Cowork.

Claude Code vs. API: When to Use Which

Heavy coding via the API can cost thousands of dollars per month in token charges for power users. Analysis from real-world usage suggests that developers doing intensive coding via API tokens might spend $2,000–$4,000+ per month, while the Max plan at $200/month covers the same workload for a flat fee. The subscription wins decisively for sustained, high-volume coding work. Use the API when you're building a product that serves other users, and use Claude Code when you're doing your own development work.

💡
Cost control for Claude Code users: Use the --model flag to pick a cheaper model for routine tasks (file organization, simple rewrites) and reserve Opus for complex architectural decisions. On Pro, monitor your usage under Settings → Usage. Batch related changes into single sessions rather than opening Claude Code for one file at a time.

Getting Started

Claude Code is installed via npm and requires Node.js. Once installed, run claude in any project directory to start a session. It reads a CLAUDE.md file in your repo root as standing instructions — use this to tell Claude Code about your project's architecture, conventions, and testing commands so you don't repeat them every session.

⚠️
Claude Code executes code on your machine. It can create, modify, and delete files, and run shell commands. Review its proposed actions before approving destructive operations. Use --no-permissions for read-only exploration sessions.

Claude Cowork — Agentic Tasks, No Terminal Required

🔬
Research Preview — Verify Before Relying On This

Cowork is an active research preview as of February 2026. Features, availability, and constraints described here reflect current documentation but may change at any time. Always check the official Cowork help article before relying on specific behaviors for important work.

Cowork takes the autonomous, multi-step execution power of Claude Code and delivers it through a desktop interface — no terminal, no command line, no developer setup. You describe a task, Claude makes a plan, you review it, and Claude works through it autonomously on your file system while you do other things.

Current Availability (February 2026)

Cowork is available as a research preview for paid subscribers (Pro, Max, Team, and Enterprise) on Claude Desktop for macOS and Claude Desktop for Windows (x64 only — Windows arm64 is not currently supported). It is not available on the web or mobile. The Claude Desktop app must remain open while Claude is working — closing the app ends the session.

⚠️
Keep Claude Desktop open. Cowork tasks run locally and require an active internet connection throughout the session. If you close the desktop app, your session ends and in-progress work may be incomplete.

What Cowork Does Well

01
File organization at scale. Point Cowork at your Downloads folder and ask it to sort by type and date, rename files to consistent patterns, or deduplicate. It processes hundreds of files programmatically — tasks that would take you an afternoon take Claude minutes.
02
Document processing pipelines. Drop receipts in a folder and ask for a formatted expense report. Scan a folder of meeting notes and produce an executive summary. Convert, merge, or restructure files in bulk without opening each one manually.
03
Research synthesis. Combine web searches, saved articles, and local notes into coherent reports. Cowork can search the web, read pages, and write findings directly into a document — all in one unattended workflow.
04
Parallel sub-agents. Unlike a single chat thread, Cowork can spin up independent sub-agents that work in parallel on different parts of a large task. Each starts with fresh context, avoiding the context accumulation that slows down long conversations.

Plugins and Connectors

Cowork supports a library of plugins for common knowledge work: productivity (calendars, tasks), enterprise search, sales workflows, and finance. Anthropic has released these as open source on GitHub. You can also create custom plugins, and if you've configured Claude in Chrome, Cowork gains browser-based capabilities: reading web pages, filling forms, and extracting data from sites that don't offer an API.

💡
Prompt Cowork with specific end states. "Analyze these documents and create a slide deck with the three main themes" gives Claude much more to work with than "help me understand this research." Vague goals produce vague plans. Specific end states — with a named output file and format — produce reliable results.
🚨
Cowork can take destructive actions. It can delete, overwrite, and reorganize files. Point it at a sandboxed folder, not your entire Documents directory, when learning how it works. Review its plan before letting it run, and keep backups of anything you can't afford to lose during the research preview.

The Claude API — Build Claude Into Everything

The API is the developer's direct line to Claude's models. It's how you build products, automate workflows, and integrate Claude into your own applications. Unlike the subscription surfaces, the API charges per token — you pay for exactly what you use, at any scale, with no monthly seat fee.

Current API Pricing (February 2026)

The following prices are from claude.com/pricing as of February 2026. Token pricing changes — always verify before building cost estimates.

Model Input ≤200K Input >200K Output ≤200K Output >200K
Haiku 4.5 $1/MTok $1/MTok $5/MTok $5/MTok
Sonnet 4.5 $3/MTok $6/MTok $15/MTok $22.50/MTok
Opus 4.6 $5/MTok $10/MTok $25/MTok $37.50/MTok
⚠️
The 200K token threshold doubles costs. Prompts over 200K tokens are charged at 2× the per-token rate for both input and output on Sonnet and Opus. If you're working with very long documents or codebases, use prompt caching or split requests to stay under this threshold.

Key API Cost Levers

01
Prompt caching: save 90% on repeated context. If you send the same large system prompt or document with every request, prompt caching stores it server-side. Cache reads cost $0.30/MTok for Sonnet 4.5 — one-tenth of the uncached input price. Cache writes cost $3.75/MTok with a 5-minute TTL (extendable to 1 hour).
02
Batch API: save 50% on async workloads. The Batch API processes requests asynchronously and charges 50% less than standard pricing. Ideal for bulk document processing, overnight analysis, and content generation pipelines where a 12–24 hour turnaround is acceptable.
03
Model selection: Haiku is 5× cheaper than Sonnet. Route simple classification, extraction, and formatting tasks to Haiku 4.5. Reserve Sonnet for nuanced writing and reasoning. Reserve Opus for the genuinely hard problems. The right model for each task is usually cheaper than defaulting to the most powerful one.
04
Extended prompt caching (1-hour TTL). For long-running pipelines where the same context is reused repeatedly over an hour, extended caching reduces cache write frequency. Check docs.claude.com for current extended caching pricing.

API vs. Subscription: When the Math Flips

For individual developers doing intensive Claude Code work, the Max subscription at $200/month is dramatically cheaper than paying API token prices for the same volume of coding activity. The API wins when you're building a product that will serve many users — you pass the per-token cost through your business model rather than absorbing it as a flat subscription. The subscription wins when you are the primary user of Claude's output.

💡
Build a cost estimate before committing. Count your expected daily requests, estimate average prompt + completion token length, multiply by the token price for your chosen model, and multiply by 30 days. If that number is under $200, the API is cheaper. If it's over $200, the Max subscription pays for itself in the first month.

Maximizing Every Tier — Tips by Subscription Level

The most cost-effective use of Claude isn't always the most expensive plan — it's the plan used intelligently. This module distills the highest-leverage tips for each subscription tier, from free to enterprise.

🟢 Free Tier — Maximize What You Have

  • Use your five Projects strategically. Create one per major ongoing area of your life or work. Upload key context once. Stop re-pasting the same background every session.
  • Front-load context in long conversations. Put your important instructions and documents at the start of the conversation, where they're most reliably attended to.
  • Avoid unnecessary Sonnet usage for simple tasks. Haiku 4.5 isn't available to free users, so use Sonnet efficiently: be specific in your prompts so Claude produces a good result in one pass rather than multiple rounds of revision.
  • Sessions reset every 5 hours. If you hit your limit, your reset isn't far away. Plan heavy work in sessions rather than spreading it across many short interactions.
  • Leverage Artifacts for reusable outputs. Ask Claude to produce code, documents, and visualizations as Artifacts — they stay accessible and can be copied or iterated on without re-generating.
  • Use web search to extend Claude's knowledge. Free users have web search. Use it to get Claude up to date on recent information rather than relying solely on its training data.
  • Connectors are available on free. Basic integrations with Slack, Notion, Google Workspace and more are free. Connect the tools you use most to reduce copy-pasting.
🔷

Pro ($17–$20/month) — Five Times More, Used Well

  • Upgrade to Opus for the right tasks. Pro gives you Opus access. Use it selectively for complex coding, long reasoning chains, and nuanced analysis. Switch back to Sonnet (or Haiku) for everything else to preserve quota.
  • Enable Extra Usage if you hit limits. Pro subscribers can opt into extra usage to continue beyond included limits at a per-use cost. Useful for occasional overrun rather than upgrading to Max for one busy day.
  • Create unlimited Projects. Pro removes the 5-project cap. Maintain a project for every client, codebase, or topic area. Your per-project instructions become your productivity compounding system.
  • Use Claude Code for development. Claude Code is included at Pro. For most individual developers, the subscription is dramatically cheaper than equivalent API usage. Start using Claude Code and stop pasting code into chat.
  • Use Research for deep dives. Pro includes the Research feature for multi-step web research tasks. Instead of doing a series of searches yourself, delegate an entire research question and get back a synthesized report.
  • Take advantage of extended thinking. Pro includes extended thinking for complex problems. Use it when you need Claude to reason through something carefully, not as a default for every request.
🔮

Max ($100–$200/month) — For Full-Time, Intensive Use

  • Know when Max pays for itself. If you're hitting Pro limits daily, Max 5× is the right upgrade. If you're doing intensive, all-day coding or analysis, Max 20× eliminates interruptions. The break-even vs. API is typically well under the API cost for heavy individual users.
  • Priority access matters during peak hours. Max subscribers get first access when Anthropic's servers are busy. If your workflow depends on Claude being available during business hours, Max's priority access has real reliability value.
  • Use higher output limits for large documents. Max includes higher output limits — relevant when generating long reports, full codebases, or comprehensive analysis that hits output caps on lower tiers.
  • Early access to advanced features. Max subscribers typically get early access to new Anthropic features before they roll out more broadly. If you want to test cutting-edge capabilities, Max keeps you at the frontier.
🏢

Team ($20–$125/seat/month) — Compound Benefits Across People

  • Mix seat types strategically. Standard seats ($20–$25/seat) cover most team members. Reserve premium seats ($100–$125/seat) for developers who need full Claude Code access or 5× more usage. Don't pay premium seat prices for users who don't need them.
  • Build shared Projects for every client and initiative. A shared Project with uploaded context, documents, and custom instructions creates a consistent AI knowledge base for the whole team. Everyone stops spending time re-explaining context.
  • Use admin controls to monitor usage. The Team plan's admin dashboard shows usage per user. Identify who's hitting limits and whether they need a seat upgrade, and identify low-usage seats that might not need renewal.
  • No model training on your content by default. Team plan content is excluded from Anthropic's training data by default — an important compliance consideration for client work and proprietary information.
  • Integrate Slack and Microsoft 365. The Team plan includes connectors for Slack and Microsoft 365. Team members can interact with Claude directly inside your existing communication tools rather than switching apps.
🔒

Enterprise — When Scale and Compliance Are the Requirement

  • The enhanced context window is a real differentiator. Enterprise's extended context (beyond the standard 200K) enables Claude to work with entire codebases, policy libraries, and legal documents in one session. This changes what's possible for document-intensive industries.
  • Audit logs and compliance API are table-stakes for regulated industries. Healthcare, finance, and legal teams typically need observability into what AI is doing. Enterprise is the only plan that provides this.
  • SCIM and SSO reduce admin overhead. Auto-provisioning users through your identity provider (Okta, Azure AD, etc.) means you don't manage individual Claude accounts — they're tied to your existing HR and IT systems.
  • HIPAA-ready plans are available. Organizations processing protected health information (PHI) can get a HIPAA-ready Enterprise plan. Required for any clinical or healthcare application.
  • Self-serve Enterprise is now available. As of early 2026, Enterprise plans can be purchased directly without going through Anthropic's sales team for straightforward deployments.

The Universal Rules That Apply at Every Tier

01
Use the right model for the task. The cheapest model that produces good results is the correct model. Default to Sonnet. Upgrade to Opus for the hard things. Use Haiku for the simple things on paid tiers.
02
Front-load your context. Give Claude everything it needs in your first message rather than drip-feeding information across many turns. Fewer, richer messages produce better results and consume fewer session resources.
03
Invest in project instructions. Time spent writing clear, specific project instructions is time saved in every future conversation. Your project instructions are the highest-leverage prompt you'll ever write for a given context.
04
Match the surface to the task. Don't use Chat for tasks that Cowork or Claude Code would handle autonomously. Don't pay API token prices for work you're doing yourself. Route each task to the surface designed for it.
05
Verify pricing before committing. Anthropic updates model prices, plan features, and availability frequently. Always check claude.com/pricing and support.claude.com before making purchasing decisions based on this or any other course.
