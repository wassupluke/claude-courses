📬 Contribute a Course

Contributions are welcome. Each course is a single self-contained HTML file that links to the shared assets/ folder for theming and components. Adding a new course is as simple as creating one file.

# 1. Fork and clone
git clone https://github.com/wassupluke/claude-courses.git
cd claude-courses

# 2. Create your course file
cp claude-cowork-course.html my-new-course.html

# 3. Edit and preview
open my-new-course.html

# 4. Update the catalog in index.html, then open a PR

The full design system — hero, sidebar TOC, callout boxes, tables, cards, quiz components, and the light/dark theme — is already available the moment you link assets/theme.css, assets/styles.css, and assets/theme.js. See assets/styles.css for a complete component reference.
